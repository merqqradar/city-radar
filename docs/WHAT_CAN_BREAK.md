# Що ламається при зміні міста — і як це виправити

Радар писався під одне місто, а потім його географію винесли в
`region_profile.py` і `data/settings.json`. Тому більшість проблем —
у **профілі**, а не в коді. Нижче — реальні пастки, від найчастіших.

## Мовчить

| Симптом | Причина | Що робити |
|---|---|---|
| Про місто пишуть, а радар мовчить | У `city_main_variants` немає потрібної форми: «Запорожье» (рос.) при «запоріжж» (укр.), давальний/орудний відмінок | Додайте корені **обох мов**. Корінь — без закінчення: «запоріжж», «запорож» |
| Не реагує на «ціль на <село>» | Села немає в `CLOSE`/`NEAR`, або корінь із помилкою | `python3 tools/find_neighbors.py`, потім `region_check.py` |
| Лише «Місто» ловиться, села — ні | Порожні `CLOSE`/`NEAR` | Заповніть профіль |
| Перестало ловитись після перейменування | Канали пишуть і стару, і нову назву | Обидві назви в корені |
| Каналів «нема» | Канал вимкнув веб-перегляд (`t.me/s/<канал>` порожня) | Такі канали працюють лише в локальному режимі з акаунтом Telegram |
| Місто — обласний центр, а тривога по «району» | Назва тривоги збігається з назвою області/міста | Перевірте `district_variants`; `final_check.py` покаже, чи розпізнається тривога вашого району |
| У логах «не задано місто» | Порожні налаштування | `python3 region_check.py` перелічить, що саме |

## Хибні спрацьовування

| Симптом | Причина | Що робити |
|---|---|---|
| Тривога на новину про удар по чужому місту | Корінь села збігається зі словом у тексті | `region_check.py` показує, у скількох повідомленнях спрацьовує кожен корінь, із прикладами. Подовжте корінь |
| Сотні збігів одного кореня | Корінь — звичайне слово (напр. «нов», «зелен») | Прибрати або подовжити до ≥ 5 літер |
| Село-тезка з іншої області | «Іванівка», «Петрівка» є всюди | У `NEAR` зі словами-винятками (`(["іванівк"], ["херсон", "запор"])`) або не додавайте |
| «центр», «аеропорт», «завод» у варіантах міста | Такі слова є в половині повідомлень | **Не додавайте загальних слів** — лише власні назви районів/мікрорайонів |
| Радар вважає ваш район «чужим» | Назви областей у `OTHER_REGIONS` збіглися з назвою села | Ненадійні корені (Черкаська, Вінницька…) вже рахуються лише поряд зі словом «область». Ваша область із цього списку виключається сама за `OBLAST_ROOTS` — тож заповніть його |
| Повідомлення про окуповані міста вашої області тривожать | Їх немає в списку територій ворога | Додайте назви в `NOT_OURS` (classify.py) — це один із рідкісних дозволених дописів у рушій |

## Про що варто знати заздалегідь

* **Мова інтерфейсу — українська.** Тексти повідомлень бота й підказки в
  `settings.py` / `monitor.py` — українською. Переклад — заміна рядків; логіку не чіпає.
* **Час.** Береться з годинника машини. У хмарі задайте змінну `TZ` (напр.
  `TZ=Europe/Kyiv`), інакше «тихі години» й час у повідомленнях зсунуться.
* **Публічні сторінки віддають ~20 останніх повідомлень.** У режимі без акаунта
  радар бачить лише свіжу стрічку. Для калібрування історії — `tools/collect_public.py --loop`
  або акаунт Telegram і `dump_history.py`.
* **Частота опитування** 20 с (`CLOUD_POLL_SECONDS` у monitor.py). Не збільшуйте
  швидкість: це чужі публічні сторінки.
* **Обмеження Telegram.** Бот не може надсилати необмежено швидко — при `429`
  радар чекає сам. Саме тому існує режим «Наліт».
* **Інтерфейс — лише macOS** (Cocoa). На Linux/Windows запускайте
  `python3 cloud_main.py`; налаштування — файлом `data/settings.json`.
* **Два екземпляри.** Основний + резервний — необов'язково й складніше. Почніть з
  одного. Помилково запущені **два основних** дублюватимуть повідомлення:
  тримайте `role: "main"` лише на одному.
* **Оновлення коду.** Свої зміни тримайте в `region_profile.py` і
  `data/settings.json` — тоді оновлення рушія їх не зітре.

## Як перевіряти будь-яку зміну

```bash
python3 region_check.py      # профіль: корені, самоперевірка, частоти по історії
python3 final_check.py       # класифікація, захист від хибних, прогін по історії
python3 test_alerts.py       # логіка звуку/серій/зняття
```

Усі три мають бути зеленими, перш ніж запускати радар у бойовому режимі.
