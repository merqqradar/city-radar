# Радар міста

Особистий монітор повітряної обстановки. Читає **публічні Telegram-канали**
моніторингу, відбирає повідомлення, що стосуються **вашого міста та його
околиць**, і пересилає їх у ваш власний Telegram-канал — коротко, з типом
загрози, місцем і посиланням на першоджерело. Закріплене повідомлення в каналі
завжди показує поточний стан.

> **⚠️ Застереження.** Це неофіційний допоміжний інструмент. Він збирає
> повідомлення сторонніх каналів автоматично й **може помилятись — і
> пропускати справжню загрозу, і піднімати хибну**. Він **не замінює**
> офіційних сигналів повітряної тривоги, застосунків і сирен. Не ухвалюйте
> рішень щодо безпеки лише на його підставі. Авторам жодних гарантій не надається.

## Що вміє

* **Рівні сповіщень.** 🔴 загроза самому місту (зі звуком) · 🟠 «поруч» (тихо) ·
  🟢 відбій / «загроза минула» · 🔵 інфо («звуки наші», робота ППО).
* **Читає списки так, як їх пишуть канали.** Тип цілі бере з потрібного рядка
  («БпЛА на село А», «FPV над селом Б» — окремі цілі), розрізняє напрямок
  («від міста» = віддаляється), не вигадує кількість, якої канал не назвав.
* **Захист від хибних тривог.** Добові зведення, новини про удари по території
  ворога, минулий час («вночі вдарили»), розмінування, збиття, звук прольоту,
  назви, що лише *схожі* на ваші села, — не будять.
* **Наліт без спаму.** Під час масованого нальоту звук — на перше повідомлення
  й при зростанні загрози (ракета, балістика, 5+ цілей), решта тихо.
* **Закріплене повідомлення** з поточним станом, кнопкою «🔄 Оновити», розбивкою
  за добу і **посиланнями на першоджерела**.
* **Знімає загрозу**, коли канали перестали про неї писати, а також коли два
  свіжі зведення по області її вже не містять; пояснює, що «вибух» міг бути
  розмінуванням, роботою ППО чи побутовим вибухом.
* **Керування з Telegram:** пауза, тиша, «зняти тривогу», звіти, перемикачі
  розумних режимів. Кожен розумний режим можна вимкнути окремо.
* **Два екземпляри з автоматичним резервом** (необов'язково): основний у хмарі,
  запасний на вашому Mac.

## Швидкий старт

Потрібен Python 3.10+ (для застосунку macOS — 3.11+).

```bash
git clone https://github.com/merqqradar/city-radar.git && cd city-radar
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

**1. Подивитися, як воно працює — без Telegram і без налаштувань.** На вигаданому
місті «Тестоград»:

```bash
python3 final_check.py --sample           # перевірка рушія
python3 test_alerts.py --sample           # перевірка логіки звуку й повторів
python3 replay.py examples/replay_demo --sample --show
```

**2. Налаштувати під своє місто.** Найпростіше — через Claude Code за готовим
промптом: **[SETUP_WITH_CLAUDE_CODE.md](SETUP_WITH_CLAUDE_CODE.md)**. Він збере
географію, підбере канали й перевірить результат на реальних даних.
Вручну: заповніть `region_profile.py` і `data/settings.json`
(див. `region_profile.py`, `settings.py`), потім `python3 region_check.py`.

**3. Підключити Telegram** (бот і канал сповіщень): скопіюйте `.env.example` у
`.env` і впишіть значення; перевірка — `python3 test_notify.py`.

**4. Запустити:** `python3 cloud_main.py` (будь-яка ОС) або застосунок macOS —
див. **[docs/RUN_MODES.md](docs/RUN_MODES.md)**.

## Із чого складається

| Файл | Призначення |
|---|---|
| `region_profile.py` | **Уся географія вашого міста** — єдиний файл коду, який заповнюєте |
| `data/settings.json` | Місто, район, канали, перемикачі (створюється при першому збереженні) |
| `classify.py`, `threats.py`, `reader.py`, `geo.py` | Розуміння повідомлень: що, де, скільки, у який бік |
| `monitor.py` | Основний цикл: дедуплікація, звук, серії повторів, зняття загроз, закріплене |
| `notify.py`, `status.py` | Відправка в Telegram, текст закріпленого й звітів |
| `public_source.py`, `cloud_main.py` | Режим без акаунта: читання публічних сторінок `t.me/s/…` |
| `menubar.py`, `gui.py`, `setup.py` | Застосунок macOS (рядок меню + вікно налаштувань) |
| `final_check.py`, `test_alerts.py`, `region_check.py` | Перевірки: класифікація, логіка звуку, якість профілю |
| `replay.py`, `backtest.py` | Прогін історії каналів через радар із підміною часу |
| `tools/` | Підбір околиць (OpenStreetMap), збір історії без акаунта, пошук сусідніх пунктів |
| `docs/WHAT_CAN_BREAK.md` | **Що ламається при зміні міста і як це виправити** |

## Приватність

* Токени й секрети живуть лише в `.env` (у `.gitignore`). У коді їх немає.
* `data/` і `logs/` теж у `.gitignore`: там ваші налаштування, ID каналу, історія.
* Радар читає лише **публічні** канали й нічого не публікує від вашого імені,
  окрім повідомлень вашого бота у ваш канал.
* Перед публікацією своєї копії коду: `git status`, перегляньте, що
  додається, і переконайтесь, що `.env`, `data/`, `*.session` не потрапили.
